# Bundled presets

Place exclusive / author `.tsa` packs here. They ship with the app as read-only library entries.

Each file is a ZIP renamed to `.tsa` with `manifest.json` + `settings.json` (see Core `TuningPresetArchive`). Optional `global-multiplier-ui.json` stores the last global-multiplier box UI snapshot for that preset.
